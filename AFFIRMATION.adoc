== What this is, and how it is designed to work

*What it is.* A short, dated, jointly-signed snapshot of what we can _honestly
and verifiably_ claim about the Oikos DSL at one exact commit. Nothing here is
marketing and nothing is a promise about the future — both of those live in the
README. This file is the receipt.

*How it is designed to work.* Three moving parts make it trustworthy:

. *Ground truth, not memory.* Every claim below was produced by _running the Rust
  toolchain in the session that wrote this file_ — `cargo build` and `cargo test`
  over the workspace. Where a status doc, the README, or a memory said otherwise,
  the live run wins and we flag the contradiction.
. *A frozen anchor.* The file names the exact commit SHA, branch, UTC timestamp,
  and toolchain (see <<Verifiable anchor>>), so "true" always means "true _at this
  point_". Move the SHA and the file becomes a draft until re-run.
. *A real signature.* It is landed by a *signed git commit*; that signature over
  this content at the anchored SHA is what makes the affirmation tamper-evident
  and attributable — not the prose alone.

*We are fallible.* This file is our best honest belief, not a proof of its own
correctness. Treat it as a falsifiable claim, not gospel.

== The epistemic contract (read this before you trust _or_ attack)

This document records our *best joint belief* at the timestamp below. It is *not
a guarantee of correctness.* We may be wrong, stale, or simply mistaken about our
own work.

*No intentional overclaim.* That is the only guarantee here: we have not
_knowingly_ inflated anything. Where something is tested we say "tested"; where a
crate is a stub blocked on an upstream milestone, we say so; where a claim is the
README's aspiration rather than a checked behaviour, we say so. If you find an
honest claim here that turns out false, that is an error to be fixed — not a lie.

*Standing invitation to refute.* You are _invited_ to bulldoze any claim here.
The fair form of the attack is: (1) read this file at the stamped commit;
(2) reproduce (or fail to reproduce) the checks in <<reproduce>>; (3) _then_ tell
us where the discrepancy is, against the artefact as it stood at this moment.

*No fights before the facts are cleared up.* Bring a reproducible discrepancy at
this commit and we will fix the claim, the doc, or the code — promptly and
without defensiveness. The goal is a corrected record, not a won argument.

== The honest state (one breath)

*Oikos (the DSL) is a real, four-crate Rust workspace that builds green and passes
71 tests with zero failures this session. Its normative guarantee — reject a model
that violates an accounting identity — is genuinely implemented and tested at the
check layer (`check_model` returns `Err(GodleyImbalance{…})` on an unbalanced
Godley matrix). The frontier is the desugar-to-Ephapax lowering, which is a stub
blocked on the upstream Ephapax parser; so the guarantee holds at the check layer
on the AST, not yet end-to-end from surface source. There is no proof assistant in
this repo — the deeper economics principle (no canonical disaggregation of a macro
aggregate) is proved in `echo-types` and cited here, not imported.*

  (`Finished dev … in 2.59s`). The four crates are `oikos-syntax`, `oikos-parser`,

  compile" is exercised by 10 green tests, not asserted by prose alone.

[#nuance]
=== The honest nuance you must not lose (tested behaviour vs the full pipeline)

The green build + tests prove that *the Rust crates compile and the stated checks
behave as written on the test inputs*. They do NOT prove:

* *that the guarantee holds end-to-end from surface source.* The MUST is tested at
  the *check layer on hand-constructed AST* (`Model` values built in the tests),
  not by running the surface parser, desugaring, and re-checking. The parser has
  its own 33 green tests, but the parser → check → desugar path is not wired as one
  pipeline, because desugar is blocked.
* *that desugaring to Ephapax IR works.* `oikos-desugar` is a stub (0 tests),
  blocked on the upstream Ephapax surface-language parser milestone. The
  `Cargo.toml` workspace deps for `ephapax-ir` / `ephapax-typing` are commented out
  for exactly this reason.
* *that the macro-economics aggregation principle is proved here.* It is not — there
  is *zero Agda toolchain in this repo*. The Sonnenschein–Mantel–Debreu /
  representative-agent "no canonical disaggregation" result is proved in `echo-types`
  (`EchoAggregation`, `--safe --without-K`) and cited at the *citation level* in
  `docs/alib-aggregate-bridge.adoc` (there is no Agda↔Rust import path).

=== Known-incomplete but honestly fenced

* *`oikos-desugar` is a stub.* Stated plainly, not green-washed.
* *OikosBot is a different product.* The `bot-integration-affine/` AffineScript port
  is in-flight and is NOT covered by this affirmation; it has its own status in
  `STATE.a2ml` / `ARCHITECTURE.md`. Do not read the DSL's green tests as OikosBot's.
* *GitHub Actions budget.* Per `STATE.a2ml`, required-checks gates are intermittently
  blocked on Actions budget; PRs in this estate are sometimes admin-merged. That is
  an operational note, not a claim about code quality.

=== Outstanding / weak (no spin)

* *End-to-end "does not compile" from source: not yet demonstrated* — gated on the
  desugar block (see <<nuance>>).
* *Desugar → Ephapax: blocked* on upstream `hyperpolymath/ephapax`.
* *`alib` aggregate library: design only* — the Route A vs B decision in
