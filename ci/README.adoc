= CI configuration (non-GitHub)

Non-GitHub CI configuration lives here. GitHub Actions workflows stay in
`.github/workflows/` because GitHub reads that path and no other.

[cols="1,3",options="header"]
|===
| File | Consumer

| `.gitlab-ci.yml`
| GitLab CI, on the GitLab mirror. *Not* found automatically at this path —
see below. Runs the same Rust gates as `.github/workflows/ci.yml` (fmt, clippy,
`reuse lint`, unit + doc tests, release build) plus a Trufflehog history scan.

|===

== Required out-of-band setting (GitLab)

GitLab looks for `.gitlab-ci.yml` at the repository root by default. Because
the file now lives in `ci/`, the project setting must be changed or *GitLab CI
silently stops running* — no pipeline, no error, no red X:

* Project → Settings → CI/CD → General pipelines → *CI/CD configuration file*
* Set it to `ci/.gitlab-ci.yml`

The file moved on 2026-10-10 as part of the root-shape alignment in
https://github.com/hyperpolymath/oikos-economics-accounting-dsl/issues/109[issue #109]
(ruling D186: align to the `rsr-template-repo` allowlist). The move is
recorded here rather than only in the commit message because the setting is
invisible to every check this repository can run: no gate in this repo can
observe another forge's project configuration, which is precisely why a note
like this one has to exist.

[NOTE]
====
The pipeline was already failing to be created before the move: the `trufflehog`
job declared `stage: security` while `stages:` listed only `lint`, `test` and
`build`. GitLab rejects that at pipeline creation ("job has an invalid stage"),
so nothing on the GitLab side was running the other jobs either. `security` is
now in the stage list.
====

== Local push/commit gate

This repository's local gate is not the `pre-commit` framework. It is the
versioned hook directory `.github/hooks/`, activated with:

[source,bash]
----
.github/hooks/install.sh
----

which sets `core.hooksPath` to `.github/hooks` and `commit.template` to
`.gitmessage`. See `.github/hooks/pre-commit` for what runs and why.
