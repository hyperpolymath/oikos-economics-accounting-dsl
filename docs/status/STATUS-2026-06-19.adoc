== Headline (one breath)

The Oikos DSL workspace (four Rust crates) **builds green and passes 71 tests,
0 failures** this session. The normative MUST — reject a model that violates an
accounting identity — is *real and tested at the check layer*: `check_model`
returns `Err(GodleyImbalance{…})` on unbalanced Godley matrices and `Ok` on
balanced ones. The blocked frontier is the **desugar-to-Ephapax** lowering
(`oikos-desugar`, 0 tests, stub), gated on the upstream Ephapax parser. So:
"a violating model does not compile" holds *at the check layer on the AST*; the
full surface-source → desugared-IR → verdict pipeline is not yet wired end to end.

== Honest cross-cutting notes

* The MUST is tested at the *check layer on hand-constructed AST* (the
  `tests/godley.rs` cases build `Model` values directly and assert reject-on-violation).
  It is not yet demonstrated from *surface source* end to end, because the
  parser→check→desugar pipeline is not fully wired and desugar is blocked.
* `README.adoc` / `EXPLAINME.adoc` call `oikos-check` "blocked / stub". The live
  run shows the **pre-desugar** accounting checks are real and green (29 tests);
  the "blocked" part is specifically the *desugar-to-Ephapax* lowering and any
  check that needs the desugared IR. We flag this drift rather than restate the docs.
* `STATE.a2ml` reports 30% / alpha and is weighted toward the OikosBot product;
  for the DSL itself, the check + parse layers are more mature than that headline
  suggests, while desugar remains the gating blocker.
